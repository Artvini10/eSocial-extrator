## 🔄 Manutenção

Estes documentos são mantidos automaticamente sincronizados com o código através de scripts Python.

Para atualizar os metadados (data, linhas de código, commit info):

```bash
python _docs/update_all_documentation.py
```

**Importante:** Os scripts de atualização estão em `_docs/`, não modifique esta pasta manualmente para atualizações.
