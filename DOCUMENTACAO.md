# 📚 Documentação e Recursos Adicionais

Toda a documentação, testes e scripts de utilidade foram organizados na pasta **`_docs/`** para manter a raiz do projeto limpa e focada.

## 🗂️ Estrutura Atual

```
extrator-esocial/
├── _docs/                  # 📚 TODA documentação, testes e scripts
├── src/                    # 💻 Código-fonte principal
├── config/                 # ⚙️  Configurações
├── logs/                   # 📝 Logs de execução
├── outputs/                # 📄 Arquivos de saída
├── .github/                # 🐙 Integração GitHub
├── README.md               # 📖 Documentação principal
├── requirements.txt        # 📦 Dependências
├── .env.example            # 🔐 Variáveis de ambiente
└── .gitignore              # 🚫 Arquivos ignorados
```
